\f0\fs24 \cf0 Stock Market Bar Project\
\
Overview\
A lightweight desktop application that I made to display real-time ETF price\
changes using a simple graphical interface. The tickers can be changed to whatever suits you.\
\
Objective:\
To build a practical and useful visualization tool while learning how to:\
- Fetch market data from public APIs\
- Perform basic financial calculations\
- Update a UI on a timed loop\
\
Implementation:\
- Python\
- yfinance for data access\
- tkinter for UI rendering\
\
Key Takeaways:\
- Working with external APIs\
- Handling time-based updates\
- Translating raw data into intuitive displays\
