\f0\fs24 \cf0 Data Engineering Utilities - Small mini-projects I built while working to refine a large, multi-dimensional dataset used for our IV Arbitrage research project.\
\
Overview:\
A collection of small scripts used to clean, enrich, and augment\
financial datasets creatively for exploratory analysis and modeling.\
\
Components:\
1) Metadata Enrichment:\
Merges ticker-level datasets with creatively sourced sector and industry classifications from Finviz\
to enable structured filtering and grouping for our deep learning model.\
\
2) Feature Engineering\
Computes realized volatility measures over multiple rolling horizons that we needed to support our exploratory quantitative analysis.\
\
Tools Used:\
- Python\
- pandas\
- NumPy\
\
Key Learnings:\
- Data alignment and schema consistency\
- Rolling-window computations\
- Feature construction for financial datasets\
